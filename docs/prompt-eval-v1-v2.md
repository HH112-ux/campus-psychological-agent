# 情绪分析提示词版本对比（V1 → V2）

## 版本信息

| 项 | V1（M3 基线） | V2（P5 正式评估） |
|---|---|---|
| 位置 | `app/services/emotion.py` `_EMOTION_SYSTEM_INSTRUCTION`（V1 版） | 同位置（V2 版，当前线上） |
| 评估集 | emotion_eval_v1.json（45 条） | emotion_eval_v2.json（59 条） |
| 严格一致率 | 39/45 = 86.7% | **51/59 = 86.4%**（go/no-go ≥80% 达标） |
| 按类：低落 | 9/12 = 75.0% | **16/17 = 94.1%** |
| 按类：平静 | 8/11 = 72.7% | 10/16 = 62.5%（另 3 条近义 ok） |
| 对抗样本 | 3/5 = 60.0% | 7/11 = 63.6% |
| 强度 MAE | 未测量（缺黄金标注） | **1.37**（目标 ≤2 达标） |

## V2 相对 V1 的改动

1. **低落 vs 焦虑边界**：明确「迷茫、无望、难熬、失去兴趣、无力」属低落而非焦虑；
   直接纠正 M3 两条误判样本（dp-07「未来一片迷茫」、dp-09「这一天好难熬」）。
   → 低落一致率 75% → 94.1%（本次评估中 dp-09 已纠正，dp-07 仍误判为 anxious）。
2. **平静 vs 还行**：明确「明确积极/放松/满意/安心/成就感 → calm；中性偏可/还行 → ok」。
   → 代价：3 条 calm 样本输出 ok（近义口径，归并后平静 = 13/16 = 81.3%）。
3. **对抗表达识别**：新增「自我安慰反话/反讽按其真实情绪判定（通常低落）」与
   「引用歌词/转述他人且非表达自己 → calm 或 other」两条细则。
   → 对抗样本 60% → 63.6%；adv-02/adv-06/adv-09/adv-10 类反话已纠正，
   转述类（adv-07/adv-08）仍误判（模型把「朋友焦虑」识别为本轮情绪）。

## 结论与后续

- **go/no-go 达标**：严格一致率 86.4% ≥ 80%；强度 MAE 1.37 ≤ 2；对抗样本 ≥10 条要求满足（11 条）。
- 线上为「本轮消息 + 前两轮上下文」输入，一致率通常高于单轮离线口径。
- 已知薄弱点（V3 候选）：转述他人情绪（adv-07/08）的归因仍不稳定；平静/ok 边界依赖近义归并
  口径。此类样本在真实对话中出现频率低，不影响 go/no-go。
- 留档：本报告与 `docs/emotion-eval-p5.md` 为 P5 正式评估依据；V1 脚本 `eval_emotion.py`、
  V1 数据集 `emotion_eval_v1.json` 保留可重放。
