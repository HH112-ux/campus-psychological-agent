### 1.2 新机制可靠性

#### a) `_normalize_with_offsets` 下标映射

实测含 emoji、全角空格、全角标点、繁简混排、增补平面汉字、组合字符：

```text
'我😭不 想 活 了'        -> '我不想活了'      [0, 2, 4, 6, 8]
'我　不　想　活　了'      -> '我不想活了'      [0, 2, 4, 6, 8]
'我真的不想活，走不动了😭' -> '我真的不想活走不动了' [0,1,2,3,4,5,7,8,9,10]
'我不想活 動'            -> '我不想活動'      [0, 1, 2, 3, 5]
```

- 长度一致、下标严格递增、单字回映与跨度回映均成立。
- 另做 20000 条随机 fuzz（字符池含 `😭 🙂 \u200b \u3000 \n \t Ａ Ｎ İ 𠮷 组合符 繁体字 全角标点`），校验 `len(norm)==len(offsets)`、严格递增、逐字回映、随机跨度回映，**0 例失败**。

结论：下标映射本身可靠，本轮误报不是映射错位导致的。

#### b) `_raw_before` / `_raw_after` 截断字符集

当前断句集为 `[。！？!?；;，,、：:…—\n\r]`，未包含 `〜 · 「」『』（）()【】[] “” ‘’ / |` 与空白。

对「我不想活{分隔符}动」实测：

| 分隔符 | 结果 |
| --- | --- |
| `，` `。` `、` `；` `：` `…` `—` | high |
| `〜` `·` `「` `」` `（` `）` `“` `”` `\u200b` `\u3000` 空格 | none（被当作「不想活动」豁免） |

结论：缺少这些分隔符确实能构造出「不想活〜动」「不想活·动」被判 none 的极端样本，但要求分隔符后**恰好只剩一个「动」**且无语义延续，属于人为构造，不构成阻断。建议把 `〜～·「」『』（）()【】[]“”‘’` 补进断句集即可，成本极低。

#### c) 白名单整词匹配的构造绕过

`_COLLISION_WORDS` 只收 `不想活动 / 不想活跃 / 寻死觅活` 三个完整词，且要求词后为空或结构助词/语气词（`_COLLISION_TAIL`）。这一收紧修好了 B-1 的三条漏报，但产生了新的误报回归：

| 输入 | 旧版本（cb8b891） | 新版本（527a346） |
| --- | --- | --- |
| 我不想活动只想躺着 | none | **high** |
| 我不想活动也不想说话 | none | **high** |
| 我不想活跃只想安静 | none | **high** |
| 寻死觅活但我没事 | none | **high** |
| 我不想活躍，只想休息 | none | **high** |
| 我今天不想活蹦乱跳 | none | **high** |
| 不想活蹦乱跳了 | none | **high** |
| 我不想活跳跳 | none | **high** |

根因在 `backend/app/services/crisis.py:165-167`：整词命中后，要求词后只能为空或 `了的着过地得吧呢啊呀哦哈啦` 之一；一旦后面跟「只想/也/但」等正常续句，就被判成「词还在延长」，回落为 high。

对比之下，以下带标点的写法仍是 none，行为不一致：

```text
我不想活动，只想躺着   -> none
我今天不想活动，只想躺着 -> none
我不想活动只想躺着     -> high
```

此外，繁体/异体不在白名单里：`我不想活動`、`我不想活躍`、`我不想活蹦亂跳` 均为 high；旧版因单字后缀集包含 `動/躍/蹦/跳` 而是 none。

这一组误报会把「不想活动、只想躺着」这类低强度表达升级为 high，直接弹危机卡片并触发值班告警，属于危机侧的行为回归。按照本轮“危机侧任一条从正确变错即阻断”的判据，计为阻断（详见 4.1）。

## 四、结论

### 4.1 是否还有阻断上线的问题

**有 1 条：B-1 危机误报回归。**

- 现象：`我不想活动只想躺着`、`我不想活动也不想说话`、`我不想活跃只想安静`、`寻死觅活但我没事`、`我不想活躍，只想休息`、`我今天不想活蹦乱跳`、`不想活蹦乱跳了`、`我不想活跳跳` 由 none 变为 high。

- 性质：方向是多报，不是漏报；不造成安全漏判，但会误弹危机卡片、误触值班告警，且与“我不想活动”必须 none 的产品口径冲突。
- 判定：按本轮“危机侧任何一条从正确变错即阻断”的判据，计为阻断。若团队明确接受“宁多报”策略，可降级为非阻断，但仍建议上线前修复。
- 修复方向（不需改架构）：整词命中且原文跨度内无标点/换行即可豁免，去掉“词后必须是句读或语气词”的限制；同时把 `活躍 / 活蹦乱跳 / 活跳跳` 等纳入白名单或做繁简归一。修完后回归 B-1 九条核心样本，确认仍全部 high/none 正确。
