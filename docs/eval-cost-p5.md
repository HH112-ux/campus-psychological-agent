# 压测与成本核对（P5）

## 压测结果（2026-10-14，本机 dev 环境）

| 项 | 结果 | 说明 |
|---|---|---|
| `/health` 并发（200 req @ 50 并发） | 吞吐 **3816 req/s**，P50 6.3ms，P95 30.4ms | 框架层承载（FastAPI + uvicorn），不含 DB/LLM 依赖 |
| 对话链路延迟（真实 LLM，非流式整轮） | 约 **5.2s**（含主对话回复 + 情绪分析） | 流式首字延迟显著低于整轮耗时；峰值并发受智谱 API 配额与单机 uvicorn 限制 |

说明：
- `/health` 不依赖 Mongo/LLM，仅验证框架与连接池承载，不代表业务接口并发上限；
- 真实瓶颈在智谱 API 并发与响应时延；业务侧已有应用层限流（30 条/小时/用户）与
  情绪分析 5s 硬超时兜底，避免分析拖慢主对话。
- 班级晚自习后峰值场景（`[假设]`）建议上线前用体验版流量再压一次真实对话并发。

## 成本估算（模型 API）

价格口径（智谱开放平台公开刊例，2026-10）：`glm-4-air` 0.001 元/千 tokens（输入+输出），
`glm-4-flash` 免费档（情绪分析 0 成本）。

单轮对话 token 构成（实测典型值）：

| 组成 | 估算 tokens |
|---|---|
| 系统提示词 | ~600 |
| 窗口记忆（近 20 轮 ≈ 40 条） | ~1200 |
| 用户消息（≤2000 字上限，典型 ~50） | ~50 |
| 模型回复（≤120 字，典型 ~60） | ~80 |
| 合计 / 轮 | ~1900 |

| 场景 | 计算 | 成本 |
|---|---|---|
| 单用户单轮 | 1900 tokens × 0.001 元/千 | ≈ **0.0019 元** |
| 单用户日均（假设活跃 10 轮） | 0.0019 × 10 | ≈ **0.019 元/日** |
| 内测 40 用户 × 日均 10 轮 | 0.019 × 40 | ≈ **0.76 元/日** |
| 月活 1000 用户 × 日均 5 轮 | 0.0019 × 5 × 1000 | ≈ **9.5 元/月** |

结论：模型成本极低，情绪分析（flash 免费）不产生成本；主要资源开销是
MongoDB 存储（消息含历史窗口，单用户年存量估算 < 1MB）与智谱并发配额。
**单用户日成本约 0.02 元，内测规模日成本 < 1 元，成本侧无 go/no-go 风险。**
