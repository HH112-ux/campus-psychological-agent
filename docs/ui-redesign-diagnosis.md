# 「心屿」小程序界面诊断与分期改造方案

> 范围：仅诊断与方案，不含任何业务代码/样式代码改动。
> 依据文档：`README.md`、`docs/repo-governance.md`、`miniprogram/README.md`、`campus-agent-dev-doc/campus-agent-dev-doc.md`、`docs/ui-style-guide.md`（现行「暖暮 · 屿」规范）。
> 合规红线（全程约束）：不输出诊断结论、不推荐药物、不宣称治疗；免责声明常驻；危机卡片语义醒目度不可弱化。

## 〇、一页速览

### 核心问题（3 条）

1. **图标与情绪表达全靠 emoji**——系统表情符号承担了图标、情绪档位、空状态插画三类角色，跨设备渲染不一致、气质低龄（🧸），是最直观的「AI 默认模板」信号。
2. **结构同质化成「三件套」**——每页都是「大标题 + 一句说明 + N 张同款白卡堆叠」，卡片圆角/阴影/内边距完全一致，页面之间没有节奏差异，像同一模板批量生成。
3. **设计令牌有名无实**——`app.wxss` 定义了 token，但 practice 页整页字面色值、logs.js 硬编码情绪色、字号实达 19 档、圆角实达 13 档、135° 渐变复用 7 处；外加 TabBar 无图标、会话上限文案三处口径不一（3 / 15 / API 的 5）。

### 改造方向（推荐 A）

| 方向 | 气质 | 一句话 |
|---|---|---|
| **A · 校园手账感（推荐）** | 纸感、便签、低刺激、被认真对待 | 最贴合「深夜倾诉 + 不被评判」的信任场景 |
| B · 呼吸留白感 | 编辑式极简、大留白、细线 | 高级但偏冷，陪伴感弱 |
| C · 岛屿 IP 插画风 | 小屿形象化、插画重 | 亲和力强但成本高、易低幼 |

### 优先级表

| 优先级 | 事项 | 预期收益 | 改动范围 |
|---|---|---|---|
| P0 | TabBar 补图标；统一会话上限口径；字号/圆角收敛到 token；practice 页接入 token | 第一眼「完成度」跃升；零结构风险 | `app.json` + 各页 wxss/js 文案 |
| P0 | 文案去「同学/客服腔/工程味」，隐藏 0/2000 字数 | 语气从模板变真诚 | 各页 wxml/js 字符串 |
| P1 | emoji 图标系统替换（情绪档位 → 自绘圆点表情，cell → 本地 PNG 线性图标） | 去掉最大 AI 味来源 | index/chat/logs/mine/memories/sessions + 新增 `assets/icons/` |
| P1 | 首页结构改版（打卡前置为今日主卡，日签/记忆合并弱化为一条） | 首页从「模板堆叠」变「有主次的桌面」 | index.wxml/wxss 结构 |
| P2 | 空状态/加载态/动效统一（手写短线插画风，240ms 缓动规范） | 细节质感 | 各页 empty/loading 区块 |
| P2 | 「我的」页分组重构（热线区视觉升级为一眼可拨） | 安全功能权重提升 | mine.wxml/wxss |

## 一、诊断依据与约束

- 目标用户：高校学生，核心画像是「深夜倾诉者·小林」（大二、考前焦虑、凌晨使用）与「观望者·阿哲」（持续低落、对真人咨询有病耻感）。见 `campus-agent-dev-doc.md` §目标用户与核心场景。
- 使用场景以**深夜、低电量、情绪负载高**为主 → 界面必须低刺激、低认知负担、无推销感。
- 技术约束：微信小程序原生 WXML/WXSS，不引入第三方框架/重型组件库（`miniprogram/README.md`）。
- 已有基础：`docs/ui-style-guide.md` 已完成一轮「去 SaaS 蓝」改造并建立了 token 与对比度校验，**色彩方向（暖青绿+暖米白）本身不是问题，问题出在图标系统、结构节奏与 token 执行**。

## 二、「AI 生成感」证据清单（文件 + 行号）

### 2.1 emoji 承担图标系统（最大来源）

| 位置 | 证据 |
|---|---|

| `pages/index/index.wxml:16` | 记忆卡用 🧸（泰迪熊），对大学生用户偏低龄 |
| `pages/index/index.wxml:33`、`pages/logs/logs.wxml:7` | 🔥 连续打卡徽章——健身/背单词类 App 的成瘾式激励符号，与「不被评判」的定位冲突 |
| `pages/logs/logs.wxml:68`、`pages/sessions/sessions.wxml:32` | 两个不同页面的空状态共用同一个 🌱 |
| `pages/chat/chat.wxml:78` | 麦克风按钮直接用 🎤 字符，录音中退化成文字「12″」 |
| `docs/ui-style-guide.md:167` | 空状态规范明文写着「居中 emoji（72rpx）」——**问题已被制度化**，需改规范而非只改页面 |

emoji 在 iOS/Android/微信各版本渲染不一致，且无法着色到品牌色，天然与「暖青绿自定义主题」打架。

### 2.2 结构同质化：标题 + 说明 + 卡片三件套

- 首页 `pages/index/index.wxml:3-88`：hero（标题+副标题）→ 日签卡 → 记忆卡 → 打卡卡 → 倾诉入口卡 → 练习入口卡，**六张卡片圆角、阴影、内边距完全一致**，纵向等距堆叠，无主次。
- 「我的」`pages/mine/mine.wxml`：资料卡 + 5 个结构完全相同的「emoji + 标题 + ›」cell，热线列表夹在 cell 之间，视觉权重与「历史会话」相同——安全功能被稀释。
- 所有页面容器padding 清一色 `32rpx`，卡片间距清一色 `24rpx`（index/mine/logs），节奏机械。

### 2.3 渐变与圆角的「默认 AI 审美」

- 135° 线性渐变共 7 处：头像（`chat.wxss:38`、`mine.wxss:21`）、新建按钮（`sessions.wxss:30`）、日签卡（`index.wxss:25`）、柱状图（`logs.wxss:74`）、危机卡两档（`crisis-card.wxss:13,18`）。渐变头像 + 渐变按钮是 AI 生成 UI 的高频指纹。
- 圆角实测 13 档：8 / 10 / 12 / 16 / 18 / 20 / 22 / 24 / 28 / 32 / 36 / 52 / 999 rpx（token 只定义了 16/22/28 三档）。
- 字号实测 19 档：22–64rpx 几乎每 1rpx 都有一档（如 25rpx 见 `sessions.wxss:89`、29rpx 见 `crisis-card.wxss:80`），且两个「hero」规格互相矛盾：首页 44rpx/600（`index.wxss:11-15`）vs 会话页 64rpx/800 + 4rpx 字距（`sessions.wxss:10-15`）——`ui-style-guide.md` 把这种随意性固化成了「Display 仅用于会话页大标题」。

### 2.4 token 体系未贯穿

- `pages/practice/practice.wxss` 整页字面色值（`#3e7a69`、`#7a736b`、`#2f2a24`），圆角 24rpx、阴影 `rgba(156,87,34,.08)` 均偏离 token——V4 新页面未走规范，说明规范没有执行机制。
- `pages/logs/logs.js:5-10` 情绪色 `#E06666` 等硬编码在 JS 里，与 wxss 语义色并存两套色彩来源。
- `components/crisis-card/crisis-card.js` 存在重复的 `data` 键（L8-11 与 L34-38），后者覆盖前者，虽无运行事故但属粗糙痕迹。

### 2.5 完成度硬伤（非审美但「第一眼露馅」）

- **TabBar 无图标**：`app.json:23-28` 四个 tab 只有 `text`，没有 `iconPath/selectedIconPath`——微信小程序里纯文字 TabBar 几乎等于「原型未完成」。
- **口径不一致**：会话上限首页/会话页写「3 个」（`sessions.wxml:5`、`chat.js:72`），`sessions.js:53` 写「15 个」，API 文档（README §5, code=2003）写「5 个」。四个数字并存。
- **假「每日一句」**：`index.js:12` 是编译期常量，永远显示同一句「情绪没有好坏，它们都只是来送信的。」——名为每日一句，实际从不变化，被用户识破即信任折损。

### 2.6 文案腔

| 类型 | 位置 | 原文 |
|---|---|---|
| 客服/官方腔 | `index.js:110-113`、`mine.js:10-11` | 「早上好，同学」；默认昵称「同学」、头像字「同」 |
| 工程口径外露 | `chat.wxml:72` + `chat.js:5` | 输入框常驻「0/2000」字数；`logs.wxml:24`「近 7 天情绪强度（1–10，无记录日跳过不补 0）」把实现细节写给用户 |
| 空泛鼓励/模板腔 | `logs.wxml:69`、`memories.wxml:33`、`index.wxml:5` | 「和我说说今天，日志会自动长出来」「我会温柔地记住」「小屿一直在这里，随时听你说」——单句尚可，全量堆叠即成「AI 陪伴模板腔」 |
| 激励语气冲突 | `index.wxml:33` | 「🔥 连续 N 天」的打鸡血语气与心理陪伴的「允许中断」价值观冲突 |

### 2.7 小结：为什么整体「老套」

色彩其实已经避开了 SaaS 蓝，但「emoji 图标 + 渐变头像 + 等距白卡 + 胶囊 chip + 大圆角 + 模板文案」这一整套正是 2023 年后 AI 生成移动端 UI 的统计中位数。**单个元素都不算错，组合起来没有一处「人为做过的决定」的痕迹**——没有自定义图形语言、没有节奏变化、没有编辑取舍，这才是「老套 + AI 味」的实质。

## 三、可选设计语言方向

### 方向 A · 校园手账感（推荐）

- **气质**：暖米白像纸，卡片像贴在纸上的便签与标签；细线分隔代替阴影；图标为手绘感细线；情绪用「低饱和色点 + 文字」而非表情脸。
- **为什么适合**：心理陪伴的第一要求是「被认真对待的信任感」。手账隐喻「这是属于你自己的记录」，天然契合打卡/日志/记忆三个核心功能；低刺激、无渐变、无发光，适合深夜使用；与现有「暖暮·屿」色板完全兼容，是**演进而非推翻**。
- **落地方式**：全部用原生 WXSS 可实现（细线 border、纸感靠底色微差 `surface-warm`、便签卡用 1rpx 边框 + 极浅阴影 + 左上角小色标）；图标为本地 PNG 细线图标包（tabBar 只接受图片，本来也必须出 PNG）。
- **风险**：手绘感把握不好会显「简陋」——靠统一线宽（2rpx）、统一圆角（便签 12rpx 小圆角）与克制配色兜底；风险低。

### 方向 B · 呼吸留白感

- **气质**：编辑式排版，大留白、细分隔线、字号层级拉开，几乎无卡片，文字本身成为界面。
- **为什么适合**：最「不 AI」的方向，高级感强；对情绪负载高的用户，留白即平静。
- **风险**：留白型界面对字体渲染与文案质量极度敏感，当前文案库存量不足会露怯；与微信用户习惯（卡片化）距离远，「开始倾诉」等主按钮需要重新设计引导强度；改造成本最高（结构重排）。风险中高。

### 方向 C · 岛屿 IP 插画风

- **气质**：把「小屿」形象化（一座小岛/一盏灯的形象贯穿空状态、加载态、练习页），插画笔触统一。
- **为什么适合**：陪伴型产品有具象形象最易建立情感连接；空状态/加载态不再是 emoji，而是「小屿在等你」。
- **风险**：需要一套风格统一的插画资产（AI 生成位图难以保证系列一致性，反而加重 AI 味）；形象一旦低幼会强化病耻感用户的「这是给小孩的吗」顾虑；资产成本高。风险高，建议仅作为远期演进，**P0–P2 不依赖它**。

> 推荐 A：与现有 token 兼容、纯 WXSS 可落地、信任感与低刺激感最强。B 的「留白与文字层级」原则可吸收进 A 的排版；C 的「形象化空状态」可作为 A 完成后的增量。

## 四、设计 token 层（收敛版，替换 ui-style-guide 对应章节）

> 原则：**先做减法**。现有色板保留（对比度已校验），只收敛形状/字阶/动效，并规定「不在表内的值禁止使用」。

### 4.1 色板（沿用，不动）

沿用 `app.wxss` 现有全部色 token；**新增纪律**：JS 不得持有色值（`logs.js:5-10` 的情绪色迁回 wxss 类名，如 `tl-badge--anxious`）；危机卡字面色值保留（样式隔离的合理例外）。

### 4.2 字阶（19 档 → 6 档）

| 层级 | 值 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| Display | 40rpx | 600 | 1.3 | 页面问候/大标题（统一首页与会话页，废弃 64/800） |
| H2 | 32rpx | 600 | 1.4 | 卡片标题 |
| Body | 30rpx | 400 | 1.6 | 正文、气泡 |
| Body-S | 28rpx | 400 | 1.6 | 次要正文 |
| Caption | 24rpx | 400 | 1.5 | 元信息、时间戳 |
| Micro | 22rpx | 400 | 1.5 | 角标、图例 |

废除 23/25/26/27/29/31/34/36/38/44/48/56/64rpx；情绪 emoji 位（48–72rpx）随图标系统一并替换。

### 4.3 间距（4 的倍数，rpx）

`8 / 16 / 24 / 32 / 48` 五档。页面边距 32，卡间距 24，卡内边距 32，紧凑列表项间距 16。现有值基本合规，仅清理 10/12/14/18/20/26 等零头。

### 4.4 圆角（13 档 → 3 档 + 2 特例）

| token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 12rpx | 便签小卡、输入框、内部色块（手账感的关键：圆角收小） |
| `--radius-md` | 20rpx | 标准卡片、气泡 |
| `--radius-lg` | 28rpx | 底部弹层、危机卡 |
| 特例 | 50% / 999rpx | 头像、胶囊按钮 |

### 4.5 阴影（2 档 → 2 档，整体更浅）

保留 `--shadow-card` / `--shadow-soft`；手账方向建议把卡片从「浮起」改为「贴上」：`0 1rpx 4rpx rgba(63,58,50,.06)` + `1rpx solid var(--line)` 边框，阴影做辅助。禁止自定义第三套阴影（practice 页 `rgba(156,87,34,.08)` 回收）。

### 4.6 动效时长

| token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | 按下/选中反馈 |
| `--dur-base` | 240ms | 卡片出现、sheet 弹出 |
| `--dur-slow` | 400ms | 呼吸动画以外的氛围动效上限 |

 easing 统一 `cubic-bezier(0.25, 0.1, 0.25, 1)`；情绪项 `translateY(-6rpx)` 选中上浮保留。呼吸引导动画（`practice`）不受 400ms 限制（功能即动画）。

## 六、文案改写原则与 before / after

**原则**
1. 不叫「同学」——默认昵称用「你」，缺省头像字用「屿」；称呼是关系定位，客服腔来自错位称呼。
2. 不把实现口径写给用户（字数、枚举值、补 0 规则）；必要信息改说人话。
3. 鼓励必须具体、允许中断——心理产品不打鸡血、不用 🔥 式成瘾激励。
4. 拟人化克制：小屿可以说「我在」，不承诺「一直/永远」。
5. 空状态说「现在可以做什么」，不说空泛比喻。

## 七、实现路径与结构复用

- **技术栈不变**：纯 WXML/WXSS/JS，不引入组件库；所有 P0 项为值替换与文案替换，零结构风险。
- **结构可复用**：现有类名与页面骨架全部保留。P1-3（首页）是唯一动 WXML 结构的项目，改动限于块级顺序调整与两个区块合并，数据字段不变。
- **emoji 替换的两条路线**：
  - 情绪五档 → **WXSS 自绘**（圆 + `::before/::after` 画眼嘴），免图片资产、可着色到情绪色；
  - cell/tabBar → **本地 PNG**（tabBar 只接受图片，必须出 PNG；一套 2px 线宽细线图标，自制约 14 枚，尺寸 81×81px）。
- **token 执行机制**：本次改造在 `ui-style-guide.md` 增补「禁用值清单」（字号/圆角/阴影不在表内即 PR 打回），并把 logs.js 情绪色迁回 wxss 类，杜绝 JS 持色。
- **安全功能保护线**：危机卡的红/琥珀语义、拨打按钮权重、「我的」页免责声明常驻，均不在弱化范围内；P2-3 是加强而非削弱。

## 八、结题汇报用：3 个「第一眼可见」的改造成果

1. **TabBar 与全页图标从 emoji 换成统一细线图标 + 自绘情绪色点**——打开产品第一秒，「完成度」和「这套图标是定制的」同时成立。
2. **首页从「六张一样的白卡」变成有主次的「今日桌面」**：问候一行、打卡主卡、一条「小屿的话」，配上手账感细线便签样式——改造前后截图对比最直观。
3. **文案口径统一且说人话**：会话上限一处口径、没有「0/2000」、没有「同学」、没有永远不变的「每日一句」——评委随手点三处都不会再撞见模板腔。
