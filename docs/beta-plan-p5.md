# 内测方案（P5：30–50 名学生体验版）

> 目标：收集「疏导有效反馈率」与「情绪日志留存率」两个 go/no-go 指标，
> 并获取危机误报体验与访谈素材。**本方案需由项目组/校方执行**，代码侧配套已就绪。

## 一、招募与投放

- **招募渠道**：班级群/学院通知/心理中心公众号；文案附体验码二维码。
- **名额**：30–50 名；建议覆盖低年级（高焦虑场景）与心理委员（可反馈体验）。
- **体验窗口**：连续 2 周（第 7–8 周）。
- **合规**：招募说明含「非医疗工具、数据加密、可随时删除、自愿参与」，并引导学生阅读隐私政策。

## 二、体验流程（最小引导）

1. 扫码进入 → 首次启动隐私同意弹窗 → 首页打卡一次；
2. 鼓励至少完成 3 次倾诉（每次 ≥ 5 轮）与每日打卡；
3. 每轮回复可点赞/点踩（点踩需带原因标签，接口已支持 feedback）；
4. 第 2 周末提交 5 分钟在线问卷（见下）。

## 三、数据口径（两个 go/no-go 指标）

| 指标 | 定义 | 目标 | 数据来源 |
|---|---|---|---|
| 疏导有效反馈率 | 点赞 /（点赞+点踩），按会话末统计 | ≥ 70% | messages.feedback（已落库） |
| 情绪日志留存 | 新用户次周仍产生 ≥1 条情绪记录的比例 | ≥ 25% | emotion_records + checkins |

统计口径代码：管理员可通过后端查询聚合（脚本可复用 `scripts/` 目录工具）。

## 四、问卷提纲（在线表单，8 题以内）

1. 你使用「心屿」的频率？（每天 / 每周 3-5 次 / 偶尔 / 基本不用）
2. 最常用功能？（倾诉 / 情绪打卡 / 看趋势 / 求助热线）
3. 倾诉后感觉？（被听见了 / 平静了一些 / 没变化 / 更烦躁）
4. 有没有哪次回复让你觉得「被说中了」？请举例（可留空）。
5. 有没有哪次危机提示让你觉得「误报 / 过度担心」？请举例。
6. 是否愿意在心情不好时再次打开它？
7. 你最想改进的一个点（开放）。
8. 是否愿意参与后续 10 分钟一对一访谈？（留联系方式，自愿）

## 五、访谈提纲（10 分钟，选择 5–8 人）

- 你通常在什么时间、什么心情下打开？
- 回忆一次印象最深的对话：它做了什么让你感觉好/不好？
- 危机提示出现时你的第一反应？
- 与真人倾诉相比，「心屿」的优势与不足？
- 什么会让你坚持使用/卸载？

## 六、坏例闭环

- 点踩带原因标签 → 每周归档 bad-case → 回流到提示词 V3 迭代与危机词库五步闭环
  （docs/crisis-lexicon-workflow.md）。
- 危机误报案例 → 走词库变更流程（回滚/调阈值），不得直接删词。

## 七、交付物

- 招募文案与体验码：项目组准备（本方案提供文案要点）；
- 在线问卷：用问卷星/飞书问卷按上述提纲创建；
- 反馈率/留存率统计：内测结束后由后端查询聚合，写入 `docs/beta-report.md`。
