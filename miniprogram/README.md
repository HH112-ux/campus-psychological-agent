# 心屿 · 微信小程序（P3 情绪识别与日志）

P1 已实现：会话列表、流式对话页、危机求助卡片、微信静默登录与本地 mock 登录。
P3 已实现：四 TabBar 结构（首页/对话/情绪日志/我的）、五档情绪打卡与连续天数、情绪日志页（7 天趋势 + 时间线 + 筛选）、对话页情绪角标、历史会话与求助热线。

## 技术栈

微信小程序原生框架（WXML + WXSS + JS），不引入第三方框架。

## 运行方式

1. 下载并打开「微信开发者工具」（稳定版）。
2. 选择「导入项目」，目录指向本 `miniprogram/` 文件夹，AppID 填 `wx641b560961211693`，后端选「不使用云服务」。
3. 先启动后端（见 `../backend/README.md`，监听 127.0.0.1:8000）；开发阶段已在 `project.config.json` 关闭域名校验（`urlCheck: false`）。
4. 本地无 `WX_SECRET` 时后端走 `WX_MOCK_LOGIN=true`，小程序 `wx.login` 拿到的 code 会被映射为固定 mock openid，无需真机即可打通登录与会话。

## P1 验收要点（回归）

- 首页可新建/进入/重命名/删除会话；并发活跃会话上限 5 个。
- 进入对话页可连续多轮对话，回复以流式逐字上屏（基础库不支持分块时自动降级为非流式）。
- 跨轮记忆：上文提到的信息（如姓名、年级）在后续轮次可被记住。
- 危机红线：输入「我不想活了」等高危句，**立即**在顶部出现红色紧急求助卡片（不可关闭）并显示固定话术，不等待大模型；输入「撑不住了」等中等信号，在回复后出现可关闭的琥珀色提醒卡；卡片热线可一键拨打。
- 弱网/模型异常时出现降级话术并保留已收内容，不出现白屏。

## P3 验收要点

- 首页按时段问候（早/午/晚/深夜）+ 每日一句 + 记忆型问候；五档情绪一键打卡（选档位 + 可选 200 字备注），打卡后展示当日结果卡片与 🔥 连续天数，同日重复打卡为「更新」。
- 对话页：每轮回复气泡下方展示「本轮识别：情绪 · 强度/10」角标（由 SSE `emotion` 事件或非流式 `emotion` 字段驱动，出现在 done 前）；历史会话重进时角标随消息恢复。
- 情绪日志页：7 天强度柱状（无记录日不补 0）、平均强度与上周对比、主导情绪、本周情绪小结（V2 周报洞察：仅描述性结论，如「焦虑多出现在晚上」，不做归因；`GET /emotion/weekly-insight` 生成、小程序只渲染）；时间线合并「来自对话（含会话标题 + 原文证据）」与「每日打卡（含备注）」两类条目，支持七类筛选与上拉分页。
- 「我的」页：历史会话入口（reLaunch 到对话页携带 session_id）、**主动关怀开关（V3）**、**练习卡片入口（V4）**、24 小时求助热线一键拨打、关于与免责声明（心屿不能替代专业心理咨询或医疗诊断）。
- 主动关怀（V3）：后端在用户连续 N 天低落或打卡中断时，经微信订阅消息送来温和问候（`services/caring.py` 每日扫描）。「我的」页「主动关怀」cell 可随时开启/关闭（`GET/PUT /users/me/caring`）；开启时调用 `wx.requestSubscribeMessage` 获取一次性订阅授权并回填（`POST /users/me/caring/subscribe`）。模板 ID 属微信侧外部依赖，未配置时前后端均安全跳过（前端 `globalData.subscribeTemplateId` / 后端 `WX_SUBSCRIBE_TEMPLATE_ID` 需一致）。
- 练习卡片页（V4，`pages/practice/practice`）：三种可交互练习——呼吸引导（按 `pattern` 缩放的吸气/屏息/呼气动画 + 倒计时）、三分钟呼吸空间（分步高亮 + 计时）、微小行动（行动清单勾选）；完成回传 `POST /practices/{id}/complete` 落库。入口在首页「练习卡片」与「我的」页。内容仅供放松与觉察、不替代专业帮助，文案 [待专业审校]（M2 联动）。
- 对话/打卡数据与后端日志页抽查一致（同一情绪来源同一枚举口径：打卡 low→低落、irritable→烦躁）。

## 注意事项

- 对话页为 Tab 页：新建会话与进入历史会话均用 `wx.reLaunch`（tab 页不可 `navigateTo`），reLaunch 时 `onLoad` 重新执行并按 `session_id` 加载或新建。
- 流式依赖基础库 `RequestTask.onChunkReceived`（基础库 2.20.1+，`libVersion: latest` 已满足）；进入对话页会用 `/health` 静默探测一次，不支持时自动改走非流式。
- 真机预览需让手机与电脑在同一网络，并把 `app.js` 的 `apiBase` 改为电脑局域网 IP（如 `http://192.168.x.x:8000`）。
- 正式提审前必须：配置 HTTPS 合法域名（后端需备案域名 + TLS）、重新开启域名校验、填入真实 `WX_SECRET` 并关闭 mock。
- 主动关怀（V3）需在微信公众平台申请订阅消息模板，并把模板 ID 填入 `app.js` 的 `globalData.subscribeTemplateId`（与后端 `WX_SUBSCRIBE_TEMPLATE_ID` 一致）；未配置时该功能静默跳过，不影响其他链路。
- 小程序内不展示、不落盘任何超出必要范围的心理敏感信息（对齐 SECURITY.md）。
