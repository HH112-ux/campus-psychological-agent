# 「心屿」隐私政策（终稿 v1.0）

**版本**：1.0（首次生效，2026-10）
**适用主体**：心屿微信小程序及配套后端服务（校园心理智能陪伴 Agent，项目代号 campus-psychological-agent）

## 一、我们是谁

心屿是一款面向高校学生的情绪陪伴小程序：学生可以随时与 AI 陪伴者「小屿」多轮对话倾诉，系统在对话中识别焦虑、低落等情绪并给出疏导建议，沉淀为个人情绪日志。**它不是诊疗工具，不提供医疗诊断、不推荐药物、不替代专业心理咨询。**

## 二、我们收集哪些信息

| 信息类型 | 内容 | 用途 |
|---|---|---|
| 微信身份标识 | 仅微信登录返回的 openid（不收集学号、手机号、姓名等身份信息） | 账号识别与数据隔离 |
| 对话内容 | 你与小屿的聊天记录 | 提供陪伴对话、情绪识别与危机预警 |
| 情绪与打卡记录 | 情绪打卡（档位+可选备注）、系统识别的情绪类别/强度 | 情绪日志与趋势展示、记忆型问候 |
| 危机风险事件 | 命中风险词库的记录（仅记命中词，不存对话原文） | 危机干预与审计 |

我们不收集：学号、手机号、位置、通讯录、相册等与陪伴功能无关的信息。

## 三、我们如何使用

- 对话与陪伴：生成共情回复；
- 情绪识别与疏导：异步分析情绪，映射疏导策略，沉淀情绪日志；
- 危机干预：本地词库同步拦截 + 模型风险判定双保险，命中时展示求助热线并引导转介真人资源；
- 产品改进：脱敏统计（如疏导有效反馈率）。

**不会**用于：广告定向、向第三方出售/共享原始对话、任何形式的「心理测评报告」输出。

## 四、存储与安全

- 对话内容采用 **AES-256-GCM 应用层加密** 存储（生产环境强制密钥）；传输全程 HTTPS；
- 服务端不落盘微信 code 等会话票据；JWT 双令牌，refresh 旋转即旧令牌失效；
- 风险事件仅记录命中词与来源，不存储对话原文；
- 密钥与安全策略：见 SECURITY.md（漏洞报告、密钥管理、应急响应）。

## 五、你的权利（PIPL 合规）

- **单独同意**：首次使用须单独同意本政策（弹窗确认），可在「我的-隐私政策与同意」重新查看/同意；
- **导出**：可随时导出你的全部数据（对话、情绪、打卡、风险事件），接口见「我的」页；
- **删除**：可一键删除全部数据；删除为软删，30 天内登录可撤销，期满物理删除；删除后各接口不再返回任何数据；
- **更正**：情绪打卡备注可随时编辑更新。

## 六、未成年人保护

本产品面向高校学生（通常已成年）。如你未满 14 周岁，请在监护人陪同下使用，并在监护人同意后提供个人信息。

## 七、免责与危机边界

- 本产品不构成医疗建议。如你正处于危机中，请立即拨打页内 24 小时求助热线或联系身边信任的人、校心理中心；
- 检测到高风险信号时，产品的责任是清晰、温和、反复地转介真人资源，而不是自行处理危机。

## 八、联系我们

项目负责人/数据控制者：心屿项目组（学校对接老师）。邮箱与联系方式以小程序「我的」页公示为准。我们将在 48 小时内响应你的合规咨询与审核意见。
