# bad-case 复盘模板（V1 反馈闭环）

> 用途：每双周对「点踩」bad-case 做一次归类复盘，把反馈数据转成可执行的迭代项，
> 形成「收集 → 复盘 → 迭代 → 回归验证」的闭环（见 [improvement-roadmap.md](./improvement-roadmap.md) §V1）。
>
> 隐私红线：本模板留档**只记归因与迭代项，不粘贴对话原文**。原文仅存在于导出文件
> （`backend/scripts/export_bad_cases.py` 产物，已 gitignore，复盘后删除）。

## 0 · 本轮窗口

| 项 | 值 |
|---|---|
| 复盘日期 | YYYY-MM-DD |
| 窗口 | 近 14 天（`--days 14`） |
| 参与人 | 产品 / 后端（必要时 + 心理中心老师） |
| 样本总量 | N 条（按原因分布见下） |
| 导出命令 | `.venv/bin/python scripts/export_bad_cases.py --days 14 --out /tmp/bad-cases.json` |

原因分布（来自导出 `summary.by_reason`）：

| 原因 | 含义 | 条数 |
|---|---|---|
| `not_understood` | 没听懂用户意思 | |
| `no_help` | 没帮上忙 / 建议空泛 | |
| `preachy` | 说教感重、像在讲道理 | |
| `other` | 其他 | |
