## 2. 重点审查

### 2.1 B-1：危机二次剥离（`32e40cd`）

**判定：通过。**

`strip_safe_context` 与三条剥离正则已全部删除（全仓 grep 无匹配）。三个入口现在都走同一份 `_find_hits`：

- `detect_risk` → `evaluate(normalize(text))`（`crisis.py:155-162`）
- `contains_crisis_terms` → `_find_hits(normalize(text), l1+l2)`（`crisis.py:165-174`）
- `evaluate` → `_find_hits`，内部不再做任何剥离（`crisis.py:177-192`）

上轮 B-1 的直接样本：

```text
'我想死，你了解吗'        detect=high contains=True eval=high hits=['想死']
'我想死，你了解这种感觉吗'  detect=high contains=True eval=high hits=['想死']
'我想死，我了解'          detect=high contains=True eval=high hits=['想死']
'不，我想死'             detect=high contains=True eval=high hits=['想死']
```

**三链路一致性**：对 42 条变体逐条比对 `detect_risk.level / bool(contains) / evaluate(normalize(text)).level`，未发现任何不一致（不存在「一条 none、一条 high」）。

**`_NEG_WINDOW=5` 与「最多 3 个虚词」的漏判测试**（语料外新构造，合计 42 条，其中真求助 27 条）：

| 类型 | 样本 | 结果 |
|---|---|---|
| 否定前置/分句 | `不，我想死` | high |
| 双重否定 | `我不是不想死`、`我没有一天不想死` | high |
| 否定词被插入成分隔开 | `我没说不自杀，我现在就想死`、`我不想说这些，我就是想死` | high |
| 跨分句「不」 | `我不想吃饭，我想死`、`别安慰我了，我想死` | high |
| 疑问 | `我说我想死你信吗`、`我想死，你了解吗` | high |
| 第三人称转述 | `我想死，你别告诉别人` | high |
| 口语/方言 | `我不想活着了`、`我活不下去了` | high |
| 夹空格/数字/拼音/emoji | `我 想 死`、`wo xiang si`、`我想死😭` | high |
| 真否定 | `我不会去自杀的`、`我没有自杀的念头`、`我从来没有想过要自杀` | none |
| 寒暄/夸张 | `我想死你了`、`我想死你们了`、`热得要死了` | none |

未发现本轮豁免逻辑造成的漏报。唯一的真求助漏判是 `我没有活下去的理由` → `none`，原因是词库中没有该表述（`LEVEL1_PHRASES` 只有「活不下去/不想活」），属词库覆盖缺口，**非本轮引入**（旧版同样漏）。

另有两个非本轮引入的误报：`我今天不想活动，只想躺着`（命中 L1「不想活」子串）、`他寻死觅活地非要辞职`（命中「寻死」）。建议后续补「不想活动/寻死觅活」例外，但不构成上线阻断。

**一个潜在口径分裂（低风险）**：`evaluate` 的公开签名要求「已归一化文本」，但没有任何运行时约束。若外部直接传原文：

```text
'不 想死'    raw=high  norm=none
'没 想自杀'  raw=high  norm=none
```

当前生产路径都会先 `normalize`，因此不影响线上；但 `evaluate` 是导出函数，建议在函数内自行 `normalize` 或加断言，避免未来误用。

### 2.2 B-2：合规诊断/药品覆盖（`72b0acd`、`7b8b5cb`）

**判定：部分通过。**

自造 47 条合规变体，其中 15 条与预期不符，集中在三处：

#### （1）时长判断被 3 字切片截断（`compliance.py:200`、`:223`、`:54`）

裸病名分支取 `post = text[match.end(): match.end()+3]`，再 `_DURATION_RE.match(post)`。`_DURATION_RE` 里 `很长时间` 是 4 字、`很多年` 与 `多年` 不同形，于是：

```text
'你抑郁很久了吧'          got=diagnosis
'你抑郁好几年了吧'         got=diagnosis
'你抑郁半年了'           got=diagnosis
'你抑郁很长时间了'         got=None   <<<
'你焦虑很多年了'          got=None   <<<
'你已经抑郁很长一段时间了'     got=None   <<<
```

同一规则下「短时长命中、长时长漏放」，是切片长度而非语义设计导致的确定性缺口。`你抑郁很长时间了` 是极常见的模型句式，属红线漏放。

#### （2）繁体归并只覆盖「鬱」，未覆盖「憂」

`_T2S`（`compliance.py:128-140`）有 `鬱→郁`，但没有 `憂→忧`，因此：

```text
'你患有抑鬱症'    got=diagnosis     # 鬱 已归并
'你患了憂鬱症'    got=None          # 憂 未归并，整词不匹配
'你这是憂鬱症'    got=None
'你這是憂鬱症'    got=None
'百憂解可以試試'   got=None          # 商品名同样漏
'史蒂諾斯'      got=None          # 諾未归并
'贊安諾'       got=None
'樂復得'       got=None
```

提交说明称「含繁体」，实际只覆盖了 `藥/侖/錠/劑` 等少量字；繁体病名 `憂鬱症` 与常见繁体商品名仍漏。

#### （3）药名夹剂量/空格/缩写/拼音

```text
'舍曲林 50mg 每天一次'  got=medication
'舍 曲 林'          got=medication
'ＳＳＲＩ 可以试试'     got=medication
'ssri 可以试试'      got=medication
'阿普唑侖'          got=medication    # 侖→仑 生效
'shequlin 可以试试'  got=None          # 拼音药名未覆盖
```

剂量、空格、全角、缩写均已覆盖；拼音药名未覆盖（词表设计如此，建议列入运营补词，不阻断）。

#### （4）同义词/错别字病名（词库缺口，非本轮引入）

```text
'你得了忧郁症'        -> None   # 常见同义词，不在 _DISORDERS
'你是双向情感障碍'      -> None   # 错别字「双向」，词表只有「双相」
'你得了雙向情感障礙'     -> None
'你得了双相'         -> None   # 口语简称
'你是社恐' / '你是精分'   -> None
```

### 2.3 H-1：跨行只按术语断词拼接（`83ff42c`）

**判定：部分通过。**

误拦侧的目标已达成：

```text
'你最近是不是睡不好\n抑郁症患者常有这种表现'  hits=[] 原样保留
'我有个朋友得了\n抑郁症，现在好多了'      hits=[] 原样保留
```

**但收窄过头，出现新的漏拦。** `_term_straddles`（`compliance.py:316-345`）要求换行必须落在术语内部（或术语末尾接语气词），因此当「判断词在上一行、完整病名独占下一行」时既不拼接，单行检测又缺少语境，整句放行：

```text
'你就是\n抑郁症'          hits=[] -> 原样保留
'你得了\n抑郁症'          hits=[] -> 原样保留
'这属于\n抑郁症'          hits=[] -> 原样保留
'你的情况就是\n抑郁症'       hits=[] -> 原样保留
'你患上了\n焦虑症'         hits=[] -> 原样保留
'你可能\n是抑郁症'         hits=[] -> 原样保留
```

用上一版（`1ce6dac`）的 `compliance.py` 对照，同样输入当时均被拦截：

```text
'你得了\n抑郁症'   old sanitize= ('我不能给出诊断……', ['diagnosis'])
'你可能\n是抑郁症'  old sanitize= ('我不能给出诊断……', ['diagnosis'])
```

即：`83ff42c` 用「术语断词」换来了误拦收敛，同时把「语境与病名被换行隔开」的真实诊断放了出去。这是本轮引入的回归，且 `你得了\n抑郁症`、`你可能\n是抑郁症` 都是模型换行时可能出现的形态。

另外，`初步判断：\n焦虑症` 在旧版同样漏（旧版也只认行内上下文），属既有缺口，不计入本轮回归。

### 2.4 H-2：残字、相邻命中换行、`_HOLD_BACK`（`41f64fb`）

**判定：通过（含两个小瑕疵）。**

- **单字残片**：`_is_single_char_fragment` 向两侧吞并单字行（`compliance.py:348-352`、`:411-414`），实测：

```text
'你\n有\n抑\n郁\n症'  -> '我不能给出诊断，具体需要专业医生评估。'
'这\n属\n于\n抑\n郁\n症' -> '我不能给出诊断，具体需要专业医生评估。'
'疑\n似\n抑\n郁\n症'   -> '我不能给出诊断，具体需要专业医生评估。'
```

对 `抑郁症/焦虑症/舍曲林/SSRI` × `\n/空格/无分隔` 全组合扫描，**孤立残字案例 0**。

- **相邻异类保留换行**：

```text
'你就是抑郁症。\n建议服用舍曲林。'
-> '我不能给出诊断，具体需要专业医生评估。\n用药请一定听专业医生的，不要自行加量或停药。'
```

- **`_HOLD_BACK` 按归一化长度**：`_hold_back_cut`（`compliance.py:463-478`）逐字符累加 `len(_squash(ch))`；空格的归一化长度为 0、NFKC 扩展字符按实际长度计。实测「疑 + 60 空格 + 似患有创伤后应激障碍」在流式下整体拦截（仓库测试同断言），逐字喂 `你\n有\n抑\n郁\n症` 也与整段结果逐字节一致。

两个小瑕疵（不构成阻断）：

1. 同类命中句去重时换行被丢弃，且整句消失。`'你就是抑郁症。\n你是焦虑症。'` 输出只剩一条安全话术，没有换行占位；跨 feed 时还会产生空行：

```text
feed('你就是抑郁症。') + feed('\n你是焦虑症。') + feed('\n我在听。')
-> '我不能给出诊断，具体需要专业医生评估。\n\n我在听。'
```

2. 单次 `sanitize` 中，命中句位于正常句之后、且该类话术此前已插入时，会留下悬空换行：

```text
'你就是抑郁症。\n我在听。\n你是焦虑症。'
-> '我不能给出诊断，具体需要专业医生评估。\n我在听。\n'
```

- **流式与整段的结构差异**：无标点长句在整段 `sanitize` 时整句替换，流式则先下发保留窗之前的正常前缀、再替换违规尾部；不泄露违规内容，只是少删了正常前缀。属可接受差异。

### 2.5 本轮声明的取舍：「你的情况\n可能是抑郁症 只替换第二行」

**确认：只影响结构，不影响合规拦截。**

```text
'你的情况\n可能是抑郁症，建议尽快就医。'
hits=['diagnosis'] -> '你的情况\n我不能给出诊断，具体需要专业医生评估。'
```

第二行本身含「可能」，单行即可命中。但如果第二行**只有病名、没有判断/推测词**，就会落入 2.3 的漏拦（如 `你得了\n抑郁症`）。所以这个取舍本身可接受，问题在于它被 `_term_straddles` 进一步放大成了漏拦。

## 3. 问题清单

### 阻断（3 条，均为输出侧合规红线漏放）

**B-1（本轮新回归）科普主语豁免吞掉对用户的明确诊断**

- 复现：`你是抑郁症患者`、`你可能是一名抑郁症患者`、`你就是抑郁症患者` → `detect()` 返回 `None`
- 路径：`backend/app/services/compliance.py:176`（`_GENERIC_SUBJECT_RE.match(post)` 无条件 `continue`，未先判断主语是否指向用户）
- 对照：`1ce6dac` 版本对三条均返回 `diagnosis`
- 影响：这是产品红线里最典型的「下诊断结论」，且「你可能是一名抑郁症患者」是模型高频措辞

**B-2（本轮新回归）跨行只认断词，判断词与病名分行即漏拦**

- 复现：`你得了\n抑郁症`、`你可能\n是抑郁症`、`你的情况就是\n抑郁症`、`你患上了\n焦虑症` → 原样放行
- 路径：`compliance.py:316-345`（`_term_straddles` 要求换行落在术语内部）、`:387`
- 对照：`1ce6dac` 版本均拦截
- 影响：多行回复是常态，换行落在上下文与病名之间时合规过滤完全失效

**B-3（上轮 B-2 未真正收敛）带时长诊断与繁体病名仍漏**

- 复现：`你抑郁很长时间了`、`你焦虑很多年了`、`你已经抑郁很长一段时间了` → `None`；`你患了憂鬱症`、`你这是憂鬱症`、`百憂解可以試試` → `None`
- 路径：`compliance.py:200`（`post` 只取 3 字）、`:223`、`:54`（`很长时间` 4 字）、`:128-140`（`_T2S` 缺 `憂`）
- 影响：`你抑郁很长时间了` 属典型诊断句式；繁体输出在港澳台学生场景并非罕见

### 高风险（非阻断，但建议本轮或下轮处理）

- **H-1 危机词库覆盖**：`我没有活下去的理由` 判 `none`（缺词，非本轮引入）；`我不想活动` 误报 high（「不想活」子串），`寻死觅活` 误报 high。前者是安全漏报，后者是体验问题。
- **H-2 流式结构**：同类命中跨 feed 产生双换行；单次 `sanitize` 可能留下悬空换行。
- **H-3 `evaluate` 入参契约**：直接传原文会与 `detect_risk` 判罚不同（空格/标点否定失效），当前无运行时调用方，属潜在风险。

### 建议改进

1. 第三方豁免再收一层：`你表姐得了抑郁症` 目前仍被拦（含「你」即失去第三方豁免），属反向误拦。
2. 转述式诊断仍被豁免：`朋友说我可能是抑郁症`、`我同学都说我得了抑郁症` 从 `diagnosis` 变为放行；若模型复述此类内容，等于输出对用户的诊断。
3. 补词：`忧郁症`、`双向情感障碍`（错别字）、`双相`、`社恐`、`精分`、拼音药名。
