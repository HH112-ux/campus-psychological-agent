# 小程序提审材料包（P5）

> 用途：微信小程序审核 + 校内/主管部门备案材料。所有「功能现状」以代码与接口实测为准。

## 一、基础信息

| 项 | 内容 |
|---|---|
| 名称 | 心屿（校园心理智能陪伴） |
| 类型 | 微信小程序（原生） |
| 建议类目 | 教育-教育信息服务 / 生活服务（校园服务）<span class="note">[以主体资质可选类目为准，必要时联系微信平台确认]</span> |
| 服务对象 | 高校学生 |
| 后端 | FastAPI + MongoDB（云端部署需已备案 HTTPS 域名） |
| 免责定位 | 情绪陪伴与记录工具，**非医疗诊断/治疗工具** |

## 二、功能自查表（对应提审功能说明）

| 功能 | 现状 | 证据 |
|---|---|---|
| 登录 | wx.login 换 openid，仅存 openid，不收集身份信息 | 后端 auth 接口 |
| 隐私单独同意 | 首次启动弹窗 + 「我的」页重新同意入口；未同意不进入使用 | miniprogram index.js / mine.js + POST /users/me/consent |
| 免责声明 | 「我的」页常驻免责声明 | mine.wxml |
| 数据导出/删除 | 一键导出 JSON、一键删除（30 天可撤销） | GET/DELETE /users/me/data |
| 对话加密存储 | AES-256-GCM 应用层加密 | app/core/crypto.py（prod 强制密钥） |
| 危机干预 | 词库拦截 + 模型双保险，求助热线常驻 | services/crisis* + emotion risk_level |
| 降级开关 | 情绪分析可关、流式可关（env 开关） | config.py emotion_analysis_enabled / stream_enabled |
| 情绪识别 | 异步分析，不阻塞对话；分析失败降级不写库 | services/emotion.py |

## 三、合规自查（审核关注点逐项）

1. **医疗边界**：全产品无「诊断/治疗/药物」表述；回复话术固定「不评判、不设教、转介真人资源」；免责声明常驻。✅
2. **隐私政策**：终稿见 `docs/privacy-policy.md`；首次单独同意 + 行权接口（导出/删除/更正）齐备。✅
3. **内容安全**：对话经大模型生成，提示词限制 120 字内共情回应，无越界输出；危机词库红线兜底。✅
4. **类目与资质**：校园陪伴属教育/生活服务类目；如平台要求《教育机构办学许可证》等资质，需以主体实际资质补充——**待学校/项目组确认主体与资质**（见"待办"）。
5. **用户协议**：建议审核前补齐《用户协议》（责任边界、账号规则），与隐私政策并列公示。

## 五、审核风险提示

- 心理/医疗类审核最敏感的是「宣称疗效」——已通过文案自查规避；若审核要求提供
  「非医疗声明」盖章件，由学校心理中心出具即可。
- 「教育信息服务」类目可能需要院校合作证明；备选类目为「生活服务」。
- 小程序「隐私协议」勾选需与平台《小程序隐私保护指引》同步（平台侧设置）。
