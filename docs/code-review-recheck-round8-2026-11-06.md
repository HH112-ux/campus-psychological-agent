### 2.2 判定

1. **后半句独立命中能力未被破坏**：只要后半句含词表词，`_find_hits` 会继续扫描后续出现位置；级别按该词本身定级（`撑不住`/`活着没意思`/`想解脱` 等 L2 为 mid，L1 为 high），不是漏报。
2. **真正的新漏报只有「反问/反讽后缀」一类**：`我不 想死 才怪`、`我不 想死 是假的` 由 high 变 none。原因是空白透明后，否定词「不」与「想死」重新同段，走否定豁免；而「才怪 / 是假的」这类翻转语义的后缀从来不在规则内。
3. **该类并非本次新造**：不带空格的 `我不想死才怪`、`我不想死是假的` 在第七轮及更早同样是 none。`a8b71c8` 只是让带空格写法与不带空格写法一致，失去了第七轮因空格断句而偶然获得的 high。因此不算「空白透明设计本身引入的新漏洞」，但确实是一条残余漏报路径。
4. **`遗书`/`安眠药` 两例** 是词表覆盖问题（词表只有「吃安眠药」等完整短语），与断句口径无关，旧版本同样不会因后半句命中；第七轮的 high 来自首句「想死」未被豁免，属误报方向的偶然拦截。

**建议（不改代码，仅记录）**：后续迭代可在否定豁免里增加「句尾翻转后缀」判定（`才怪 / 是假的 / 怎么可能 / 巴不得`），并把上述两例补进语料；优先级低于本次上线评估，因为不带空格写法历来如此，且属低频反讽表达。
